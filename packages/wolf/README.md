# wolf

Pack DNS / zone-signing infrastructure tooling.

- `coredns-nsec3sign/` — CoreDNS plugin for on-the-fly NSEC3 signing of zones
  rendered by [otter](../otter/src/dcim/services/dns.py).
- `hickory-prom/` — Hickory DNS Prometheus exporter sidecar.
